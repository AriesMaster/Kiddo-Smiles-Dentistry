# Kiddo Smiles Dentistry

A frontend prototype with separate [sign-in](login.html) and [sign-up](signup.html) pages. The accompanying JavaScript handles form submissions in the browser. Open either page locally to inspect the forms.

This repository documents an early dental booking concept. [BrightSmile Dental](https://thabo.netlify.app/brightsmile.html) is the later full-stack portfolio project.
